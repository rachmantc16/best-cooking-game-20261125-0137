**Dapur Ceria** — an original cooking game. Run a cheerful little kitchen for one 120-second shift: read the order board, grab ingredients from the shelf, grill the patty, egg, noodles and chicken until they are *just* done (too long and they burn!), assemble each plate exactly as ordered, and serve it before the customer's patience runs out. Faster service earns bigger tips, and serving streaks build a score combo. Playable with mouse and keyboard (number keys pick ingredients, Q/W collect the grill, Space serves).

Everything on screen — the kitchen, the order board, the ingredient shelf, the assembly plate, the shift timer and the finished plates on the serving pass — is drawn by the game's own code, with no network requests.

## Run it

```sh
node main.ts
```
